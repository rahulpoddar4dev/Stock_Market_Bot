# Trading Bot Starter

This is an algorithmic paper-trading and automated execution bot using Fyers API v3 and AI analysis.

## Setup

1. Install libraries:

```bash
pip3 install -r requirements.txt
```

2. Copy the example environment file:

```bash
cp .env.example .env
```

3. Open `.env` and add your real API keys.

4. Run:

```bash
python3 main.py
```

## Safety

`DRY_RUN=true` means the bot will not place real orders. Keep this on while testing.
